# Quintiliano Tecnologia (quintiliano.com.br)

Site institucional da Quintiliano Tecnologia (INQ · Instituto de Inteligência Cibernética Quintiliano Ltda).
HTML, CSS e JS puros, publicado pelo GitHub Pages. Sem rastreamento, sem cookies, fontes servidas pelo próprio site.

- As páginas são geradas por `scripts/gerar.py` (topo, rodapé e contato em um lugar só). Depois de editar, rode `python3 scripts/gerar.py` e publique os arquivos gerados.
- Mesmos endereços do site antigo: `/`, `/institutos/`, `/pericia/`, `/solucoes/`. `/insights-2/` (vazia no antigo) leva ao início.
- Contatos em `CONTATO`, no topo do `scripts/gerar.py`.
- Teste local: `python3 -m http.server 8090` na raiz.
